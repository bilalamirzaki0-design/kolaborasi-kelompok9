Hiasan dinding Pixel Art dan Key & Time

x = harga 1 hiasan dinding Pixel Art

y = harga 1 Key & Time

2x + y = Rp 140.000

x + 3y = Rp 195.000

Eliminasi

6x + 3y = Rp 420.000

(6x + 3y) − (x + 3y) = 420.000 − 195.000

5x = Rp 225.000

x = Rp 225.000 ÷ 5 = Rp 45.000

Substitusi

2(45.000) + y = Rp 140.000

y = 140.000 − 90.000

y = Rp 50.000

Hiasan dinding Pixel Art: Rp 45.000 / pcs

Key & Time: Rp 50.000 / pcs

Kipas Topi dan Tas Kabel

A = harga 1 Kipas Topi

B = harga 1 Tas Kabel

Paket 1: A + B = Rp 120.000

Paket 2: A + 2B = Rp 190.000

Eliminasi

(A + 2B) − (A + B) = 190.000 − 120.000

B = Rp 70.000

Substitusi

A + 70.000 = Rp 120.000

A = 120.000 − 70.000

A = Rp 50.000

Kipas Topi (A): Rp 50.000 / pcs

Tas Kabel (B): Rp 70.000 / pcs

Keytime dan Robot

x = harga 1 Keytime

y = harga 1 Robot

x + 2y = Rp 140.000

3x + y = Rp 195.000

Eliminasi

3x + 6y = Rp 420.000

(3x + 6y) − (3x + y) = 420.000 − 195.000

5y = Rp 225.000

y = Rp 225.000 ÷ 5 = Rp 45.000

Substitusi

x + 2(45.000) = Rp 140.000

x = 140.000 − 90.000

x = Rp 50.000

Keytime: Rp 50.000 / pcs

Robot: Rp 45.000 / pcs
